# 星晶三消 (Crystal Match-3)

單一 HTML 檔的三消遊戲原型（Canvas 2D、離線可玩、localStorage 存檔）。

- 300 關、10 個世界、體力系統、每日任務、成就
- 11 套外觀（含聖誕、春節限定）、暖色可愛風介面
- 開啟 `index.html` 即可遊玩

## 測試版開關
`CFG.playtest = true`：全部外觀與背景解鎖、商店與付費關閉、無插播廣告。
上架前改成 `false`，並移除檔案底部的 `window.__m3` 測試掛鉤。

## 參數
所有可調數值集中在檔案內的 `CFG`（體力、廣告次數、價格、限定外觀販售期間）。

## 狀態
原型階段。廣告與購買目前都是模擬，尚未接上真實 SDK。
